## 🏴 Hakkında

**SANCAK**, Discord botlarının gelişmiş yönetim anlayışından ilham alan, Telegram toplulukları için geliştirilmiş özel bir bot altyapısıdır.

Moderasyon, yönetim, otomasyon, klon bot sistemi ve topluluk araçlarını tek bir merkezde birleştirir.

## ⚙️ Sistem Özellikleri

### 🛡️ Moderasyon ve Güvenlik
- Merkezi kullanıcı engelleme sistemi
- Ana bot ve klonlarda ortak yetkilendirme
- Yönetici ve kurucu kontrolü
- Zorunlu kanal üyelik sistemi

### 🤖 Çoklu Bot Altyapısı
- Kişisel klon bot oluşturma
- Birden fazla botu tek merkezden yönetme
- Klon botların ortak sistem altyapısı
- Token doğrulama ve şifreli veritabanı kaydı

### 🛠️ Yönetim Paneli
- Yönetici sistemi
- Kullanıcı ve grup istatistikleri
- Toplu duyuru sistemi
- Merkezi yönetim araçları

### 👥 Topluluk Araçları
- Üye etiketleme sistemi
- Eğlenceli topluluk duyuruları
- Tek kullanıcı etiketleme
- Grup üyesi kayıt sistemi

## 🚀 Teknolojiler

- Python 3.12
- Aiogram 3
- PostgreSQL
- AsyncPG
- Cryptography
- Heroku

## 🔐 Güvenlik

Sistem merkezi veritabanı üzerinden yönetilir. Klon bot tokenleri veritabanında şifrelenerek saklanır.

## ⚠️ Önemli Bilgi

Sistem, Discord Bot API sınırları dahilinde çalışır. Bot yalnızca karşılaştığı ve kaydettiği grup üyelerini tanıyabilir; Telegram üzerinden bütün grup üyelerini otomatik olarak listeleyemez.
